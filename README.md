# İngilis dili, imtahana hazırlaşaq

Azərbaycandilli istifadəçilər üçün ingilis dili öyrənmə saytı: qrammatika dərsləri, lüğət (9 000+ söz, səsləndirmə ilə), danışıq ifadələri, phrasal verbs, fellər cədvəli, flashcard-lar və sınaq testləri.

Sayt statik HTML/CSS/JS-dir, quraşdırma tələb etmir. `index.html` faylını brauzerdə açmaq kifayətdir (yerli server tövsiyə olunur).
